# Maze

This is a simple 2D Tron-theme maze game built in Java Swing & AWT for Windows

## Installation

Make sure Java JDK and Apache Ant is installed in PATH

```bash
cd "C:\Users\%user%\Documents\GitHub\as91606-7-digital-tech-simple-labyrinth\Maze"
ant run
```
